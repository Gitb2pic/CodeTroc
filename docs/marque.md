# Marque codetroc

**La pièce fendue** : une pièce (la monnaie) coupée par le « / » du code ; les deux
moitiés glissent l'une contre l'autre, deux devs qui échangent. Le nom s'écrit
`codetroc`, en minuscules, à côté du symbole.

| Rôle | Fond clair | Fond sombre |
|---|---|---|
| Moitié gauche (`--brand-a`, aussi l'accent de l'app) | `#5A4BFE` | `#9A90FF` |
| Moitié droite (`--brand-b`) | `#00C2A8` | `#00C2A8` |
| Encre | `#0E1116` | — |
| Papier | `#F7F8F3` | — |

Géométrie (relevée sur le fichier de référence, reproduite dans
`frontend/src/components/Brand.tsx`) : deux demi-disques de rayon 40, coupe
inclinée à 15°, écart de 8 entre les moitiés, glissement de 11,2 le long de la
coupe. Variante monochrome pour les petites tailles (`<CoinMark mono />`).

Application conçue et développée par **LabTools**.
